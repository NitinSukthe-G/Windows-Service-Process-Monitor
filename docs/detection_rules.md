The agent ships **30 rules**, each mapped to a MITRE ATT&CK technique.

## Severity model

| Score | Severity | Meaning |
|---|---|---|
| 9-10 | CRITICAL | Near-certain malicious behaviour or multiple independent indicators |
| 6-8 | HIGH | Strong indicator that needs prompt investigation |
| 3-5 | MEDIUM | Unusual - investigate when time allows |
| 1-2 | LOW | Informational / weak signal |

Independent rules that fire for the same process, service or startup item are combined by **CORR-001**, which raises the severity (e.g. unsigned + staging directory + double extension).

## Rule details

### PROC-001 - Suspicious parent-child process chain

A process that should not normally spawn shells or script hosts (Office, PDF readers, browsers, web servers, WMI, script hosts, accessibility tools) did so.

- **MITRE ATT&CK:** T1204.002 - User Execution: Malicious File (Execution)
- **Response:** Review the full process lineage and command line, isolate the host if the chain is unexpected, and inspect the document or service that triggered it.

### PROC-002 - Process running from user-writable directory

The executable runs from Temp, Downloads, Public, Recycle Bin or a similar location commonly used to stage malware. AppData locations only alert when the binary is not validly signed.

- **MITRE ATT&CK:** T1036 - Masquerading (Defense Evasion)
- **Response:** Verify the file origin, hash it, and submit it to a reputation service. Remove it if unknown.

### PROC-003 - Unsigned process not on the allowlist

The process is not on the allowlist and its executable has no valid Authenticode signature.

- **MITRE ATT&CK:** T1036 - Masquerading (Defense Evasion)
- **Response:** Confirm the software is approved; add it to config/custom_rules.json if legitimate.

### PROC-004 - Blacklisted tool or malware name

The process name matches a known offensive tool, credential dumper, tunnelling tool or crypto-miner on the blacklist.

- **MITRE ATT&CK:** T1003 - OS Credential Dumping (Credential Access)
- **Response:** Treat as an incident: isolate the host, capture memory, and reset exposed credentials.

### PROC-005 - System process running from wrong location

A core Windows binary name (svchost.exe, lsass.exe, ...) is running outside its expected directory - a classic malware camouflage technique.

- **MITRE ATT&CK:** T1036.005 - Masquerading: Match Legitimate Name or Location (Defense Evasion)
- **Response:** Treat as malicious until proven otherwise; collect the binary and compare its hash with a clean one.

### PROC-006 - Look-alike process name

The process name is one or two characters away from a critical Windows process (e.g. scvhost.exe, svch0st.exe) and is not validly signed.

- **MITRE ATT&CK:** T1036.004 - Masquerading: Masquerade Task or Service (Defense Evasion)
- **Response:** Inspect the binary, its parent and network activity; remove if not a legitimate product.

### PROC-007 - Unexpected parent for critical system process

A critical Windows process has a parent other than the one Windows always uses (e.g. svchost.exe not started by services.exe). This is a sign of spoofing or injection.

- **MITRE ATT&CK:** T1055 - Process Injection (Defense Evasion)
- **Response:** Dump the process and its parent for analysis and verify with an EDR/Sysmon process-creation log.

### PROC-008 - Suspicious command line

The command line contains a known attack pattern: encoded PowerShell, download cradles, LOLBin abuse, shadow-copy deletion, firewall/Defender tampering and similar.

- **MITRE ATT&CK:** T1059 - Command and Scripting Interpreter (Execution)
- **Response:** Decode and review the command, identify the launching parent, and hunt for the same pattern fleet-wide.

### PROC-009 - Duplicate singleton system process

More than one instance of a process that Windows only ever runs once (lsass.exe, services.exe, wininit.exe) exists.

- **MITRE ATT&CK:** T1036.005 - Masquerading: Match Legitimate Name or Location (Defense Evasion)
- **Response:** The newest instance is almost certainly malicious; capture and terminate it.

### PROC-010 - SYSTEM-level process from non-standard path

A process runs as SYSTEM / service account from outside Windows or Program Files and without a valid signature.

- **MITRE ATT&CK:** T1543 - Create or Modify System Process (Privilege Escalation)
- **Response:** Identify the installing service or task; privilege-escalation or persistence is likely.

### PROC-011 - Executable missing on disk

The process image path no longer exists on disk - the binary was deleted after launch (or the process was hollowed).

- **MITRE ATT&CK:** T1070.004 - Indicator Removal: File Deletion (Defense Evasion)
- **Response:** Dump process memory before termination; the on-disk artefact is gone.

### PROC-012 - Double-extension executable

The executable is named like a document (invoice.pdf.exe) to trick the user.

- **MITRE ATT&CK:** T1036.007 - Masquerading: Double File Extension (Defense Evasion)
- **Response:** Quarantine the file and review the delivery channel (email / download).

### PROC-013 - Invalid or missing signature on system binary

The signature is invalid / hash-mismatched / untrusted, or a binary in the Windows directory is unsigned - possible tampering or trojanised binary.

- **MITRE ATT&CK:** T1553.002 - Subvert Trust Controls: Code Signing (Defense Evasion)
- **Response:** Compare the file against a known-good copy (sfc /scannow) and investigate how it was modified.

### PROC-014 - Known-bad file hash (IOC match)

The SHA-256 hash of the running executable matches an entry in config/ioc_hashes.txt.

- **MITRE ATT&CK:** T1204 - User Execution (Execution)
- **Response:** Confirmed malicious by threat intelligence - begin incident response.

### SVC-001 - Service binary in user-writable directory

A Windows service executable lives in Temp, AppData, Public, Users or another directory writable by standard users.

- **MITRE ATT&CK:** T1543.003 - Create or Modify System Process: Windows Service (Persistence)
- **Response:** Disable the service, collect the binary, and review how it was registered (event 7045).

### SVC-002 - Unquoted service path

The service image path contains spaces and is not quoted, allowing Windows to execute an attacker-placed binary earlier in the path.

- **MITRE ATT&CK:** T1574.009 - Hijack Execution Flow: Path Interception by Unquoted Path (Privilege Escalation)
- **Response:** Quote the ImagePath value in HKLM\SYSTEM\CurrentControlSet\Services\<name>.

### SVC-003 - New service since baseline

A service exists that was not present when the baseline was captured.

- **MITRE ATT&CK:** T1543.003 - Create or Modify System Process: Windows Service (Persistence)
- **Response:** Confirm an approved install; otherwise disable it and investigate. Re-baseline with --update-baseline once reviewed.

### SVC-004 - Modified service since baseline

The binary path, start type or logon account of an existing service changed since the baseline.

- **MITRE ATT&CK:** T1543.003 - Create or Modify System Process: Windows Service (Persistence)
- **Response:** Check change records; a changed binary path or SYSTEM logon account is a strong persistence indicator.

### SVC-005 - Service removed since baseline

A baseline service no longer exists (informational; may be an uninstall or anti-forensic clean-up).

- **MITRE ATT&CK:** T1070 - Indicator Removal (Defense Evasion)
- **Response:** Confirm an approved uninstall.

### SVC-006 - Non-standard autostart SYSTEM service

An auto-start service running as LocalSystem has a binary outside Windows / Program Files and is not validly signed.

- **MITRE ATT&CK:** T1543.003 - Create or Modify System Process: Windows Service (Persistence)
- **Response:** Validate the vendor and installer; move to a least-privilege account if possible.

### SVC-007 - Suspicious service command line

The service image path launches a shell or script engine, or contains an attack pattern (PsExec / Metasploit-style service creation).

- **MITRE ATT&CK:** T1569.002 - System Services: Service Execution (Execution)
- **Response:** Disable the service and review event 7045 / 4697 for the creating account.

### SVC-008 - Weak permissions on service binary or folder

Standard users (Everyone / Authenticated Users / Users) can modify the service executable or its directory, allowing replacement with a malicious binary that runs as the service account.

- **MITRE ATT&CK:** T1574.010 - Hijack Execution Flow: Services File Permissions Weakness (Privilege Escalation)
- **Response:** Remove write access for non-administrators on the binary and directory.

### SVC-009 - Unsigned or invalid-signature service binary

The service executable outside the Windows directory has no valid signature, or its signature is invalid / tampered.

- **MITRE ATT&CK:** T1553.002 - Subvert Trust Controls: Code Signing (Defense Evasion)
- **Response:** Verify the vendor; submit the hash to a reputation service.

### SVC-010 - Weak permissions on service registry key

Standard users can modify HKLM\SYSTEM\CurrentControlSet\Services\<name>, allowing them to change ImagePath and run code as the service account.

- **MITRE ATT&CK:** T1574.011 - Hijack Execution Flow: Services Registry Permissions Weakness (Privilege Escalation)
- **Response:** Reset the key ACL so only SYSTEM and Administrators have write access.

### SVC-011 - Blacklisted service binary

The service executable matches a known offensive or remote-execution tool (e.g. PSEXESVC).

- **MITRE ATT&CK:** T1021.002 - Remote Services: SMB/Windows Admin Shares (Lateral Movement)
- **Response:** Identify the remote source and the account used; treat as lateral movement.

### PERS-001 - New startup entry since baseline

A Run/RunOnce registry value or Startup-folder item exists that was not in the baseline.

- **MITRE ATT&CK:** T1547.001 - Boot or Logon Autostart Execution: Registry Run Keys / Startup Folder (Persistence)
- **Response:** Verify the entry with its owner; remove it if unrecognised.

### PERS-002 - Startup entry in suspicious location or command

A startup entry launches code from a user-writable directory, an unsigned binary, or a command line matching an attack pattern.

- **MITRE ATT&CK:** T1547.001 - Boot or Logon Autostart Execution: Registry Run Keys / Startup Folder (Persistence)
- **Response:** Remove the entry and collect the referenced file.

### PERS-003 - New scheduled task since baseline

A scheduled task exists that was not present in the baseline.

- **MITRE ATT&CK:** T1053.005 - Scheduled Task/Job: Scheduled Task (Persistence)
- **Response:** Review the task action, author and trigger.

### PERS-004 - Scheduled task with suspicious action

A scheduled task runs a binary from a user-writable directory, an unsigned binary, or a command matching an attack pattern.

- **MITRE ATT&CK:** T1053.005 - Scheduled Task/Job: Scheduled Task (Persistence)
- **Response:** Disable the task and collect the referenced file.

### CORR-001 - Multiple indicators on one entity

Two or more independent rules fired for the same process, service or startup item, which raises confidence far above any single indicator.

- **MITRE ATT&CK:** - - Behavioural correlation (Multiple)
- **Response:** Prioritise this entity - independent signals agreeing is the strongest evidence this tool produces.
